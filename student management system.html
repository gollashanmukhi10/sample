Student Management System - Git Branching

Student Management System

Git Branching and Merging Demonstration

1. Create Main Branch

git init
git branch -M main
git add .
git commit -m "Initial commit"

2. Student Registration Branch

Student Registration Module

Register students using their ID, name, and course.

git checkout -b student-registration
git add .
git commit -m "Add student registration module"

3. Student Result Branch

Student Result Module

Enter student marks and calculate the result.

git checkout main
git checkout -b student-result
git add .
git commit -m "Add student result module"

4. Merge Both Branches into Main

git checkout main
git merge student-registration
git merge student-result

5. Display Git History

Click the button to display Git history.

6. Result

Both student registration and student result modules are merged into the main branch.
